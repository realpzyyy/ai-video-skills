# 阶段 0：环境、插件与多模态能力预检

## 输入、动作、产物、验收

- **输入**：用户原片/现有工程、处理范围、目标平台/画幅/时长、参考风格、既有授权与约束。不要要求用户重答已有信息；只问影响实施的缺项。
- **判断与动作**：盘点当前环境实际能力，分清本机与云端、工具与 skill、发现与验证，建立可运行路径。
- **产物**：`capability-report.json` 与项目中的制作约束。可附 `local-probe.json`，但它仅是辅助检测结果。
- **验收**：每个本阶段必需能力有已验证执行路径，或具名的人工接管方式；未知状态没有被当成可用。某下游阶段待人工验收，不妨碍先完成安全的独立工作。
- **失败处理**：区分未安装、当前不可调用、认证失败、依赖缺少、素材不可读、预算/网络限制和结果不合格。检查替代路径，必要时停在受影响的阶段并请求决定。

## 检查能力，不绑定供应商

| 能力 ID | 要证明什么 | 可行路径举例，非强制依赖 |
| --- | --- | --- |
| media_read | 当前执行环境能读取这份素材及媒体信息 | 媒体工具、编辑器、素材连接器 |
| transcribe | 能获得与源时间对应的语音文本 | 校对过的字幕、转写服务、本地 ASR |
| image_inspect | 实际画面可送入有视觉理解的模型/工具，或具名人工检查 | 原生图像输入、视觉分析工具、用户看样张 |
| audio_review | 实际音频能被听审，或安排人工试听 | 音频输入/分析能力加试听、用户试听；仅 ASR 不足 |
| image_generate | 需要时能生成位图，明确服务/授权/输入限制 | 已可用的生图服务；不是模型名称的隐含能力 |
| graphic_author | 能制作所需图表、贴纸、排版或动画 | SVG、HTML/CSS、Canvas、编辑器图形能力 |
| render_composite | 能把资产合成为所需的视频格式 | 编辑器、视频渲染框架、媒体工具与兼容浏览器 |
| person_segment | 需要背景专用蒙层时能持续识别人像 | 系统框架、本地模型、编辑器分割功能 |
| asset_access | 字体、图片、音效等资源可读取且使用条件满足 | 已提供或获准使用的资源，不假定联网或授权 |

所需能力由本次范围决定。保留原声不必检查 TTS；没有人像分离需求时分割能力可记 `not_required`。不要因某个可选插件缺失阻塞全项目。

## 四层工具检查

安装/更新阶段先按 [环境初始化](setup.md) 补齐已获授权的运行依赖。剪辑阶段先读取同机 runtime-report.json，验证并使用其中的绝对路径；不能因为新 Agent 的 PATH 不同就重复提示未安装。尚未授权新增安装则保持只读检查。

1. **指南**：技能可读且适用于当前宿主。读过指南不等于执行过其服务。
2. **调用**：通过当前工具目录/发现机制确认真正可调用的工具，读取当前 schema；已安装列表不足以证明当前 agent 获得调用权限。
3. **依赖与权限**：检查必要登录、服务连接、文件访问、运行时、字体、模型文件、导出格式；不要输出密钥、Cookie、令牌或完整环境变量。
4. **最小验证**：优先只读健康检查、读取指定素材、渲染最小本地测试帧。认证/目录存在只证明对应层；实际任务输出仍需阶段验收。

仅用宿主暴露的元数据和可观察结果判断能力，不按 Astra 或其他型号名称、模型自述推断。验证不清楚就写 `untested`，不擅自判定“不支持”。不为预检无授权地上传私人视频、下载大模型、安装软件或发起付费生图。

## 各 agent 的复核

本 skill 不默认创建多个 agent；是否委派遵守宿主规则及用户范围。已有多个 agent 时：

- 主 agent 生成全局报告；各执行 agent 读取本次任务所需的 skill/reference，并检查自己能读取对应素材、调用对应工具。
- 内容角色重点查媒体/转写；视觉角色查图像检查、素材、字体和渲染；合成角色查时序、素材、编码；验收角色查实际画面、音频与最终文件。
- 不能继承一句“主 agent 已有权限”作为本 agent 的验证。共享报告提供线索，本 agent 至少验证当前暴露的工具与文件访问。
- 同一未变环境复用近期证据；换会话、模型、主机、后端，或发生权限/调用失败时，复核受影响项。不每次循环全盘扫描。
- 不同 agent 交接需带原片身份、最新时间线版本、风格批准记录、负责的产物路径及待验收问题，避免并发覆盖。

## 制作路线与降级边界

| 情况 | 可以继续的路径 | 必须说明的限制 |
| --- | --- | --- |
| 有视觉理解与生图 | 位图样张或现有资产，结合代码/编辑器制作动态 | 生图不等于分层资产，也不等于可编辑动画 |
| 有视觉理解，无生图 | HTML/SVG/图表/排版/几何贴纸与已有素材 | 不承诺复杂写实插画、材质细节等价 |
| 无视觉理解，有代码与渲染 | 导出样张和动态预览，交可用视觉工具或用户检查 | 程序、OCR、尺寸检测不能代替整体视觉验收；状态保持待视觉确认 |
| 无音频听审 | ASR、响度/峰值/解码检查后安排人工试听 | 不声称已听过或剪口自然 |
| 无人像分割 | 保留背景、重构画幅、完整真人视频框、相关 cutaway | 含原背景的圆形裁切不是人像抠图；不能把统一蒙层称为人物后方蒙层 |
| 无视频渲染 | 先完成内容方案、资产与预览，补齐/选择合成路径 | 不把 HTML 或工程文件交付成“已完成视频” |

三套风格推荐必须与能力路线联动。不要先承诺复杂三维场景，再静默换成平面卡片。工具替换但输出等价、成本与数据边界不变时可继续；改变已批准视觉语言、质量、成本或素材外传范围时先说明并取得相应确认。

## 可选本地探测脚本

使用当前可用的 Python 3 运行：

```sh
python3 <skill-directory>/scripts/probe_local.py --media <absolute-local-video> --output <project>/local-probe.json
```

路径是占位示例，运行时替换为已核实的实际路径，不直接执行尖括号。脚本只使用标准库，检测本机 FFmpeg/FFprobe/Node 命令并对指定本地文件运行 FFprobe，不联网、不安装、不渲染、不读取凭证。输出文件使用独占创建，不覆盖已有报告。

它不能探测当前大模型真实看图/听音能力、云插件认证或视频美术质量；这些项仍必须由 agent 记录证据。命令可执行仅作为检测提示，不自动升级成端到端能力通过。
