# 声音、全片验收与交付

技术检查、美术检查、听感检查是不同证据。工具退出码、哈希或尺寸不能证明画面好看、语音自然；抽帧不能证明完整动态稳定；转写不能代替听审。

V2.1 另查：实际画面与 G2 样张的母版构图/颜色、字幕字号/断句/材质、真人窗和对象层级一致；每段语义 B-roll 不是竖线/姓名标签替代。比对最长字幕与入场/落定/退出及连续播放；无法看图时保持待人工视觉确认。style_id 一致本身不证明实际渲染一致。

## Q1 确认音频的保持与必要处理

- **输入**：G1批准的音频文件、源映射、用户选择的声音处理范围。听感确认在视觉之前完成，最终只复核是否被错误改变或错位。
- **判断**：是否有截字、爆音、底噪、异常静音、声画不同步、音量突变；是否真的需要音乐/音效。
- **动作**：先确保人声清楚自然，再按已选范围做降噪、音量统一、有限动态处理或混音。用当前工具检测响度、峰值与解码，结合实际听审。没有必要或没有获选时不增加 BGM/SFX。
- **产物**：实际声音处理记录、完整预览或混音结果、听审与机器检测结论。
- **验收**：连续听完语音不费力，没有明显断词、突发爆音、误混入 B-roll 声音或重要内容被音乐压住；抽查切口与首尾。目标平台有明确规范时核验当前规范，不把单一 LUFS 值当全平台硬标准。
- **失败处理**：定位具体切口或音轨修正；不会听音的模型可以做机器检查，但将听感交用户/可用听审路径，记录 `human_review_required`，不可宣称已听审。

默认保留G1批准音频：兼容AAC可直接封装；批准WAV时最终编码AAC一次，并检查时长、偏移和意外混音，不能声称有损码流与WAV相同。音频来自同一批准母带且无变更时复用已完成听审，不强制再开一轮用户确认；技术检查不能冒充新的听审。新改台词/剪口必须重开G1。

纯视觉修改时只重验受影响画面和声画同步。完整解码、关键字幕准确和必要视觉检查不能为凑10分钟跳过；可批量检查，复用可靠证据，异常再扩大范围。

## Q2 全片质量检查

**输入**：实际完整渲染文件、源/时间线身份、风格规范与用户确认范围。

**产物**：含检查者/方式、实际时间点、结论、问题和修复状态的 QA 记录。给问题写具体位置和后果，不用无依据的“专业级 95 分”。

| 项目 | 可观察的通过标准 | 验证方式 |
| --- | --- | --- |
| 内容 | 句意完整、顺序正确、无未经授权的新台词；事实限定仍在 | 对照编辑脚本与实际原声 |
| 字幕 | 关键字准确、与当前时间线一致、无乱码/溢出/遮挡 | 校对全文；看最长句与复杂画面 |
| 真人 | 面部与重要动作完整，背景处理不误伤人物，肤色无明显跳变 | 看普通帧、最大位移、低头/转头连续片段 |
| B-roll | 与台词相关、保护内容未被裁掉、示意与证据分清 | 看入场/落定/退出；核对来源与数字 |
| 动画 | 意图清楚、阅读时间足够、无意外截断/错层/抖动 | 连续播放代表场景与转场；关键帧辅助 |
| 风格 | 字体、材质、色彩、光照和图标在同一系统内 | 同时比较人物与各视觉场景 |
| 声音 | 人声清楚、剪口自然、无突发错误、无不需要的音乐/音效 | 听审全片、重点切口；机器检测辅助 |
| 视频文件 | 目标规格与实际一致、音视频轨完整、时长合理、能完整解码 | 媒体探测和完整解码；实际播放器回看 |
| 发布画面 | 手机尺寸可读，重要内容不被目标平台界面遮住 | 已核实的目标平台界面/模板叠加或预览，不公开发布 |
| 工程 | 能定位实际编辑入口、素材和字体依赖，交付类型准确 | 工程读取/打开或可执行检查，列出未验证环境 |

检查整个成片，不只最漂亮的截图。用户未指定平台时按通用画幅和阅读性检查，标明平台界面适配尚未验证；不能假定一个固定底部像素值对所有平台有效。

**失败处理**：按内容、时序、声音、布局、素材、人物分割或渲染分类，修复相应步骤并重验受影响范围。需要新素材、新工具授权或改变已批准风格时暂停相关制作，明确缺项。相同失败不要无变化地无限重试；保留可恢复的项目状态。

## Q3 完成状态与交付

| 状态 | 可以说什么 | 不能说什么 |
| --- | --- | --- |
| 只有方案/代码 | 方案/工程已生成 | 成片已做好 |
| 样张/资产生成 | 风格候选或素材已生成 | 动态 B-roll 已完成 |
| 成片已渲染，缺视觉或听审 | 已导出待检查版本，并列出谁需检查什么 | 完整验收通过 |
| 技术与适用的视觉/听审通过 | 对已验证范围可以交付；列出已接受的局限 | 所有环境/平台都验证过、保证流量 |

用户只要求修改局部时，验收重点为局部变化及受影响上下游，不要求把历史项目全部重做。但如遇明显新发现的严重问题，说明而非隐瞒。

交付最小集合：

1. 真正可打开/播放的 MP4 或用户要求的实际格式。
2. 最终字幕文件；若后端不能独立导出，则如实说明而非伪造文件。
3. 实际可编辑工程与必要素材、可用字体/依赖说明。它可以是本地渲染工程、编辑器工程或原生草稿，以实际产物为准。
4. 简短版本摘要：改了什么、保留什么、未做什么、已知限制与验收范围。
5. 来源/生成说明与恢复入口；主动处理、用户等待、冷启动和返工耗时。未核实许可的资产不要标“可商用”。

默认不交付封面、独立粗剪视频或独立G3样片。不强制为了这些文件再次渲染；用户另有要求时按范围增加。

成片使用高于源文件的输出尺寸时说明人物真实细节仍受源限制。工程依赖本机路径、符号链接、系统字体、云账户时，不声称已成为跨电脑独立运行包。

不自动发布到平台、写外部知识库、创建远程项目、发送消息或采购资源。这些需要对应请求/授权。制作通过与市场效果分开，未发布数据不能证明完播、涨粉或转化。
