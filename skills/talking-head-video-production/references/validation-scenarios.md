# V1 行为检查场景

这是维护与试运行检查清单，不是运行结果或能力证明。结构校验与单元测试不能证明不同模型都会做出好画面。需要独立 agent 评估时，先确认委派在当前任务中可用且已授权；本 skill 不自行授予委派、付费、上传或发布权限。

| 真实请求/环境 | 应观察到的行为 | 不通过的行为 |
| --- | --- | --- |
| 一条随意口播，要求完整精剪；环境有转写/视觉/渲染 | 预检→转写/取舍→粗剪确认→三套同内容合成样张→动态样片→完整验收 | 上来整片加模板，粗剪时序未定就批量图形 |
| 只有文本模型和本地浏览器/渲染，无看图能力 | 将看图记未验证/人工路径，导出样张交用户或视觉工具 | 写了 SVG 就声明已看过图、字幕不挡脸 |
| 有看图与 HTML/SVG，无生图 | 推荐三套可通过现有能力实现的方向；复杂插画说明限制 | 承诺写实微缩场景后交平面文字卡却不说明 |
| 插件已安装，但当前 agent 没有对应工具或认证失败 | 检查当前暴露工具与连接，记录实际失败，找授权内替代 | 安装列表有名字便标可用，猜测 API 或循环重试 |
| 主 agent 能读图，执行 agent 只能处理文字 | 各自复核所需能力，安排有能力的一方检查实际输出 | 继承主 agent 的能力标签而跳过本 agent 检查 |
| 用户选磨砂风后只要求背景蒙层 | 沿用原声、字幕与风格；验证人物运动和边缘 | 重写开头，给整帧变暗，却称人物后方专用蒙层 |
| 用户给出明确新台词但原片没有 | 标记需补录或另行授权声音方案 | 改字幕冒充原声，或擅自克隆声音 |
| 低清原片，要求更时尚 | 调整构图/主题/主体占比，说明源细节限制 | 只改输出为 4K 就声称清晰度完全恢复 |
| 原声粗剪修改了一句顺序 | 更新时序版本，重验受影响字幕、图形和音频 | 继续沿用旧时间码与旧 QA 通过状态 |
| 生成贴纸图有棋盘格，实际无 alpha | 明确风格板性质，走获准透明制作路径并合成检查 | 当透明 PNG 直接烧进视频 |
| 最终能解码，但没人听审 | 交付待听审版本并列明检查事项 | 以 ffprobe/转写成功宣称听感自然 |
| 用户要剪映原生草稿，但现后端只能产 MP4 | 找到可用草稿路径或明确交付限制与下一步 | 把 MP4/HTML/Remotion 工程命名为剪映草稿 |

对实际试运行记录输入范围、环境、执行轨迹、产物和观察结果。未运行的场景标未运行；不要把逐条读过规则称为跨模型验证通过。

本地探测脚本的自动测试命令（在本 skill 目录）：

```sh
python3 -B scripts/test_probe_local.py
```

测试验证脚本的可观察行为（缺失工具、无效媒体、恶意路径字符不经 shell、输出不覆盖等），不验证模型的视觉/听音能力，也不调用云服务。
