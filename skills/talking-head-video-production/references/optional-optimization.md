# 可选内容优化：不替代剪辑质量

仅当用户选择结构优化、内容提升、传播策略或发布复盘时启用。核心流程的逻辑连贯与事实正确仍是必需，不因本模块可选而放弃。

## 可选动作

| 动作 | 判断问题 | 执行边界 |
| --- | --- | --- |
| 更早点题 | 开头是否能让目标观众知道在讲什么、与自己何关 | “前几秒讲清楚”是可调整策略，不是强制制造冲突或保证流量 |
| 结论/结果前置 | 最值得看的信息是否埋得过晚 | 重大重排先说明；新写开头与原声分开，不未经授权生成配音 |
| 强化理解节奏 | 复杂概念是否需拆开、一项项揭示 | 不机械每两秒切画面、不把字幕动画越多当越好 |
| 证据补充 | 观众是否能看到真实过程与依据 | 索取真实后台/录屏/前后对比；示意不能升级成证据 |
| 结尾收益 | 看完是否获得一个可用结论或明确下一步 | 不空许尚无计划交付的课程、模板或效果 |
| 发布后复盘 | 谁留下、看了多久、哪里流失/重看、是否收藏或关注 | 只用获准提供/访问的数据；同平台、同口径、近似题材/长度比较 |

建议与实施分开记录。用户只要求视觉返修时，可以简短指出结构优化机会，但不据此改原声、发布 A/B 版本或执行外部运营动作。

## 方法参考与使用边界

以下为本 skill 编写时参考的公开方法页面，并非每次运行时的实时平台规范：

- [TikTok Creative best practices](https://ads.tiktok.com/resources/help/article/creative-best-practices?lang=en)：开头主张、内容结构、界面安全区等。其范围是广告经验，不等于抖音/小红书自然流量公式。
- [Wistia B-roll 方法与对照案例](https://wistia.com/blog/b-roll)：B-roll 应与叙述相关，镜头长度跟随信息任务和节奏。是制作方法，不是最新趋势排行榜。
- [Descript 口播制作教程](https://www.descript.com/blog/article/tips-for-making-a-talking-head-video-that-people-want-to-watch)：收音、光线、自然表达与辅助画面。不要把营销说法当独立效果证明。
- [YouTube 留存解读](https://support.google.com/youtube/answer/9314415?hl=en)：流失和重看需要结合内容解释；不同产品/时长/数据量的报告条件不同。

若用户询问当前规则、工具功能或特定平台指标，先核验当前官方信息。不要把一个平台的指标定义和门槛搬给另一个平台，也不要把高留存波峰直接解释成观众喜欢，重看也可能因为没讲清。
