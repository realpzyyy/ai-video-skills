# AI 口播精剪工作流

将已有口播做成“内容成立、听感自然、人物呈现得体、画面帮助表达”的成片。核心为内容剪辑与视觉包装；运营技巧是可选优化，不是基础质量门槛。

本 skill 提供跨工具的制作规范，不自带转写模型、图片生成服务或视频渲染器，也不保证每个宿主拥有相同工具。先核验实际能力，再选择执行路径。全新制作默认走完整流程；局部修改、分析或复盘只运行请求涉及的步骤，不因触发 skill 擅自重剪、发布或改造工程。

## 开始与路由

1. 先读 [能力预检](references/preflight.md) 和 [项目记录](references/project-record.md)。核实素材、任务范围、工具和多模态能力；有本地执行环境时可运行 `scripts/probe_local.py` 辅助检查。
2. 内容转写、逻辑取舍、粗剪：完整读取 [内容 SOP](references/content-sop.md)。先完成原声时间线，再提交包装层。
3. 选择或改变视觉方向：完整读取 [风格系统](references/style-system.md)。根据内容与画面展示三套可落地样张供用户选择。
4. 人物包装、B-roll、字幕、贴纸、动画：完整读取 [视觉 SOP](references/visual-sop.md)。先做代表性动态样片，再批量。
5. 完整合成、声音与交付：完整读取 [验收与交付](references/acceptance.md)。验收实际渲染结果，不只检查代码或素材存在。
6. 用户选择优化开头、信息节奏、结尾或发布复盘时，才读 [可选内容优化](references/optional-optimization.md)。

引用路径相对本 skill 目录，不是项目工作目录。首次进入某阶段时读完整相关参考，不以摘要代替。外部插件被选为执行后端时，读取该环境实际提供的对应 skill 和工具 schema；不要把另一产品的调用名称或 JSX 约束照搬过来。没有外部 skill 也可以按本文规范执行已验证的能力路径。遵守宿主对图像编辑、浏览器和工具发现的强制路由，不用本 skill 的替代路径绕过这些要求。

## 质量层级

- **硬性验收**：原话和事实不失真、关键字幕正确、声画时序正确、重要信息不被误遮挡、素材来源与生成性质明确、实际输出可用。
- **可配置默认**：保留原声；字幕通常一至两行；采用一个共享视觉系统；原片与历史版本保留。默认不新增配音、数字人、配乐或音效；需要时作为明确选择的处理项。
- **可选优化**：开头提前说明价值、调整结构、增强结尾、发布后测试。不要将“每两秒切一次”“必须前三秒制造冲突”或固定风格当硬标准。

## 三个主要确认点

| 确认点 | 给用户看什么 | 未确认前的边界 |
| --- | --- | --- |
| G1 原声粗剪 | 完整粗剪、删改摘要、不确定内容 | 不批量制作依赖这条时间线的字幕和视觉素材 |
| G2 风格选择 | 同一句台词、同一真人画面的三套合成样张与推荐理由 | 不自行替用户选定并批量展开 |
| G3 动态样片 | 最有代表性的短片段：真人处理、字幕、B-roll/贴纸及实际运动 | 不把静态样张当动态验收通过 |

常规自动步骤记录结果即可，不每步询问。明确局部修改沿用已确认的相关条件，不重复确认未变化内容。用户明确要求无停顿端到端执行时，可略过等待，记录采用的临时方向及理由；不能记录为“用户已选定”。该授权不包含新增付费、安装、云上传、改声线、发布或其他范围扩张。

## 不可丢失的制作约束

- 编辑脚本首先是原话的取舍与重排。每个保留原声能定位到源素材；新写台词必须单独标记，不伪装成原话，不默认克隆声音补录。
- 删除口误、失败尝试和无意义等待，保留逻辑连接、条件、否定与自然断句。字幕校对不是偷偷改写原声。
- 原声时间线变更后，标记依赖它的字幕、B-roll、动画、音频和 QA 为待重验，只重做受影响部分。
- 图片理解、音频听审、图片生成、代码绘图、渲染是独立能力。能写 HTML/SVG 不代表能看见结果；渲染成功不代表视觉合格。
- 生成关键帧是美术确认，不等于动画完成；透明棋盘格可能是图像内容，不等于真实 alpha。
- 实际主体始终来自原片，除非用户另行授权重绘或替换。背景蒙层不得误压暗脸部；低清素材放大输出不能称为恢复真实细节。
- B-roll 必须增加解释、证据、情境或覆盖剪口的价值。先确认用途，再选实拍、录屏、图表、插画或生成素材。不可把示意图伪装成真实数据、界面或结果。
- 动画必须体现语义或引导注意力；共享风格不等于所有信息都套同一个卡片。保留可读停留，不用持续乱动来填时间。
- 缺少必要能力时先寻找可用等价路径；影响质量或改变已选风格时说明差异并取得确认。不能静默降级或无限重复同一失败调用。

## 记录与交付

使用 [项目记录](references/project-record.md) 管理阶段、能力证据、选段映射、风格选择和验收。区分 `已规划`、`已制作`、`已渲染`、`已验证` 与 `待人工确认`。保持原片、批准条件和最新时间线是事实来源。

最后交付真实成片路径、字幕、实际可编辑工程类型、必要素材/来源说明和检查结果。只交付生成过的东西：MP4 不是剪映草稿，HTML 预览不是视频文件。未完成听审或视觉检查时，明确交付为待检查版本，不宣称完整验收。

若用户需要迁移环境，说明本次实际工具及尚未验证的依赖，不声称本 skill 会自动赋予工具、权限或多模态能力。用于维护本 skill 的回归案例见 [行为检查场景](references/validation-scenarios.md)。
